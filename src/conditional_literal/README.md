# Conditional literal categorical specialization

The files in this directory are canonical function bodies, included once at the
original definition site and instantiated again with a finite symbol-remapping
set for conditional literal categorical evaluation. They are shared source, not
independently maintained statistical implementations.

The original instantiation retains its prior preprocessed signature, attributes,
body tokens and call graph. Direct regression continues to call those original
owners. Conditional native entries and the private conditional R transport call
the literal variants; do not redirect the original entry points.

`NP_CF316_LITERAL` admits exact categorical constant identities only. It removes
near-bound/near-constant approximation from conditional X and Y factors, including
scalar, permuted, beta and profile replay paths. Imported categorical gate values
are discarded and rebuilt under the literal policy; continuous-kernel and profile
eligibility decisions retain their established meanings. The finite remapping
set is explicit at each instantiation site and undone immediately afterward.

This specialization adds no estimator, solve, ridge, rank, basis or search
implementation. Changes to a canonical body affect both instantiations unless
explicitly guarded and reviewed. Preserve every original owner's successful-path
work, and inspect calls and function addresses in both preprocessed graphs.

Before maintaining this boundary, read `AGENTS.md` and the conditional-only
exception authority. The implementation evidence is retained under
`tmp/cf316_literal_policy_20261014_r1`: `native_design`,
`implementation_native_r1/IMPLEMENTATION_SEAL.json`,
`implementation_native_r1/REVERSE_GRAPH_RECONCILED.json`, and
`evidence/PREPROCESSED_COMPARISON.json`. Those are provenance for this change;
future edits require fresh token/edge conservation and focused numerical,
capability, MPI, portable and per-owner cost evidence. A passing option flag or
numerical comparison alone does not prove tree, hardware or rank-owned execution.
